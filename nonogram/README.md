# Nonogram 數織解謎 (Picross 邏輯像素拼圖)

一個功能完備、設計精緻且支援全平台（電腦與行動裝置）的 HTML5 Nonogram（數織 / 像素拼圖）純前端網頁應用程式。免安裝任何後端或編譯環境，雙擊 `index.html` 即可在現代瀏覽器（Chrome、Edge、Safari、Firefox）立即暢玩！

---

## 🌟 核心特色功能

### 1. 豐富的精選冒險關卡庫 (30+ 關卡)
- **5×5 新手啟程**（10 關）：溫暖愛心、開懷笑臉、新鮮蘋果、晴雨小傘、濃郁咖啡、調皮幽靈、閃爍鑽石、常青樹、黃色小鴨、璀璨星星。
- **10×10 趣味進階**（10 關）：勇者之劍、能量蘑菇、深海鐵錨、榮耀皇冠、太空火箭、經典手把、俏皮小貓、向日葵、海盜骷髏、長壽海龜。
- **15×15 邏輯考驗**（6 關）：古老城堡、遠航帆船、富士山與櫻花、智慧貓頭鷹、搖滾電吉他、太空宇航員。
- **20×20 專家殿堂**（4 關）：深海巨獸、神奈川巨浪、街機遊戲機、傳奇神龍。
- **通關彩色像素畫揭曉**：每一道謎題在通關時，都會以完整的精美彩色像素畫驚艷呈現，並搭配歡慶紙花特效與勝利旋律！

### 2. 智慧邏輯提示與解題推導引擎 (Solver)
- **純邏輯重疊推導演算法**：絕非單純「透視答案」，而是依據行列線索進行重疊法（Overlapping）、邊緣法（Margin Deductions）與死角排查。
- **教學式提示訊息**：點擊「💡 邏輯提示」時，系統會指出當前最適合推導的行列，並以繁體中文清楚解釋推導原因（例如：「*第 3 列 (線索: [4])：透過重疊邏輯推導，中間第 2、3 格必定填色！*」），並以金色呼吸光芒高亮該格子！

### 3. 多重輸入操作與防手滑設計
- **滑鼠操作**：左鍵填色（■），右鍵標記叉叉（❌），滾輪縮放。
- **智慧拖曳方向鎖定 (Direction Lock)**：連續拖曳畫線時，系統自動鎖定水平或垂直方向，徹底防止手滑畫出斜向歪線。
- **行動裝置與觸控支援**：底部常駐「填色 / 打叉 / 疑問 / 橡皮擦」工具切換列，手機觸控滑動順暢。
- **全鍵盤快捷鍵**：
  - `W` `A` `S` `D` 或 方向鍵：移動游標格子
  - `Space` 或 `Z`：填色
  - `X`：標記打叉
  - `C`：標記疑問 (?)
  - `E` 或 `Delete`：橡皮擦清除
  - `Ctrl + Z`：復原 (Undo)
  - `Ctrl + Y`：重做 (Redo)
  - `H`：獲取邏輯提示
  - 點擊行列數字：可手動將線索數字畫上刪除線（經典數織標記技巧）

### 4. 完整的輔助與挑戰機制
- **行列完成自動補叉 (Auto-cross)**：當某行或某列填色方塊已達成條件時，自動為該行其餘空格填上叉叉，大幅提升解題流暢感（可在設定中開啟/關閉）。
- **十字準心高亮**：滑鼠懸停時自動高亮所對應的行、列與線索。
- **挑戰模式切換**：
  - 休閒計時模式：失誤僅記錄次數，輕鬆解謎無壓力。
  - 嚴格挑戰模式：3 顆心心生命值，累積 3 次失誤即判定失敗。
- **自動存檔與斷點續玩 (Resume Game)**：遊戲過程中隨時記錄進度，若意外關閉或重新整理網頁，可一鍵繼續遊玩未完成棋盤。

### 5. 原創關卡編輯器 (Level Creator)
- 支援 5×5、10×10、15×15、20×20 尺寸設計。
- 繪製像素圖案時，實時動態計算上方與左側線索。
- 內建色盤與自訂色彩選擇器，自製專屬的「通關揭曉彩色圖」。
- **一鍵唯一解驗證**：自動檢測謎題是否為純邏輯可解、是否存在多組解或矛盾。
- **分享碼匯出 / 匯入**：將自製關卡轉為 Base64 代碼，一鍵複製分享給朋友或貼上匯入。

### 6. 圖片轉數織黑科技 (Image to Nonogram)
- 拖曳上傳任何照片、頭貼、Logo 或圖標（PNG、JPG、WEBP、SVG）。
- 支援網格尺寸調整（5×5 至 20×20）。
- 即時調節黑白閥值（Threshold）與對比度增益（Contrast）。
- 支援 **Floyd-Steinberg 誤差擴散網點 (Dithering)** 演算法，將真實人像與複雜風景照片轉為高辨識度的數織拼圖！
- 自動萃取主色調，轉化為具備彩色揭曉的專屬關卡，並支援一鍵立即遊玩或保存至自訂庫！

### 7. 4 款高顏值主題風格與 Web Audio 合成音效
- **4 大視覺主題**：
  1. 🌑 潮流深色 (Dark Mode) - 舒適護眼，極致對比
  2. ☀️ 簡約淺色 (Light Mode) - 清爽俐落，明亮優雅
  3. 👾 經典 Game Boy 復古綠 (Retro Green) - 經典掌機點陣懷舊風
  4. ⚡ 賽博霓虹 (Cyberpunk Neon) - 螢光紫藍粉，科幻炫彩
- **無外部音檔的 Web Audio API 程式化音效合成**：
  - 方塊填色木琴 Pop 音
  - 打叉標記清脆 Tick 聲
  - 橡皮擦 Swoosh 擦除音
  - 線索標記切換音
  - 行列完成清脆和弦鈴聲
  - 失誤警示 Buzz 音
  - 通關慶祝大調七和弦 Victory 凱旋樂章
  - 支援靜音與自訂音量控制

## 🚀 快速開始

1. 打開本專案資料夾：
   ```
   桌面/nonogram/
   ```
2. 直接使用任意瀏覽器點開 `index.html` 即可開始遊玩！

## 📁 檔案結構說明

```
nonogram/
├── index.html              # 應用程式主進入點與 UI 介面架構
├── css/
│   └── style.css           # 4 套主題樣式、響應式棋盤、動畫與特效
├── js/
│   ├── audio.js            # Web Audio API 音效合成引擎
│   ├── levels.js           # 30 道精選關卡資料與線索生成器
│   ├── solver.js           # 邏輯交集推導與唯一解驗證演算法
│   ├── board.js            # 數織棋盤資料模型、歷史堆疊 (Undo/Redo) 與驗證
│   ├── storage.js          # LocalStorage 遊戲存檔、自訂關卡與設定持久化
│   ├── image-converter.js  # 圖片轉數織、網點演算法與色彩萃取模組
│   ├── editor.js           # 關卡編輯器、分享代碼編解碼
│   └── app.js              # 主控制器、拖曳方向鎖定、快捷鍵與畫面渲染
└── README.md               # 專案詳細說明手冊
```
